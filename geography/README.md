# Bounded geographic supplement

The origin is the exact KSC LC-39A coordinate in the IBM CSV, not a surveyed launch-pad polygon. Values in geography_results.json are minimum distances within the acquired OSM ways and Census Incorporated Place polygons. They are not global nearest-feature claims.

The closest OSM highway-tagged object is a private driveway. Secondary and tertiary candidates are also tagged private. Motorway, trunk and primary classes were absent from the acquired boxes. Titusville is measured to its incorporated boundary, not its centre. Census designated places and unincorporated settlements are excluded.

This folder contains distance results and source references. Distances are limited to the acquired features. The full map still needs a visual review.

Sources: OpenStreetMap API 0.6 and ODbL attribution at https://www.openstreetmap.org/copyright ; US Census TIGERweb Incorporated Places layer at https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/tigerWMS_Current/MapServer/28 .
